MUNDO MÁGICO — versão modular

Arquivo principal: index.html
CSS: css/style.css
Engine: js/game.js
Dados editáveis: data/

Para adicionar conteúdo sem mexer no index:
- Armas extras: data/weapons.js
- Skins extras: data/skins.js
- Ajustar fases: data/stages.js
- Ajustar inimigos existentes: data/enemies.js
- Ajustar bosses existentes: data/bosses.js

Observação técnica:
- O comportamento do jogo foi mantido.
- A engine principal ainda controla mecânicas complexas.
- Criar um comportamento totalmente novo de boss/inimigo exige suporte na engine, mas novos conteúdos baseados nos comportamentos existentes podem ser adicionados pelos arquivos data.
